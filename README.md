# sourcing-skill
Professional procurement sourcing skill library, including AI role prompts, supplier screening logic, sourcing workflow, supplier qualification standards and cost analysis rules.

## Included skill

### AI寻源需求澄清Skill V1.1

Location: [`AI寻源需求澄清Skill/`](./AI寻源需求澄清Skill/)

This skill turns an incomplete procurement request into a structured sourcing requirement card and reusable sourcing prompts. It supports:

- one-question-at-a-time requirement clarification;
- stopping clarification at about 80% completeness;
- quick, deep, and quick-then-deep sourcing modes;
- short replies such as `A1`, `B2`, and `C2`;
- keyword matrices, supplier evidence chains, A/B/C/D screening, and manual feedback writeback.

Start with [`00_启动口令.md`](./AI寻源需求澄清Skill/00_启动口令.md), or read [`skill.md`](./AI寻源需求澄清Skill/skill.md) for the complete workflow.
