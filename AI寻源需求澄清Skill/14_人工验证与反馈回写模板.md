# 14 人工验证与反馈回写模板

本模板用于候选供应商电话验证和后续经验沉淀。只记录能影响判断的信息，保持轻量。

## 一、电话验证表

每家实际联系的企业复制一份：

```text
公司名称：
联系结果：已接通 / 未接通 / 已加微信 / 已回复资料 / 其他
是否生产厂家：是 / 否 / 未确认
是否能做：能 / 不能 / 需看图纸或样品 / 未确认
是否愿意打样：愿意 / 不愿意 / 需收费 / 未确认
大致报价：
主要问题：
处理结论：合格备选 / 待观察 / 排除
```

电话中无法核实的内容不要替对方补结论；涉及生产身份、关键能力、资质或报价时，尽量要求书面资料佐证。

## 二、反馈回写表

对有复用价值的验证结果记录：

```text
公司名称：
AI推荐原因：
人工验证结果：
AI判断是否准确：准确 / 部分准确 / 不准确
错误原因：
新发现的行业关键词：
是否加入供应商库：是 / 否 / 待观察
下次寻源应注意什么：
```

错误原因可简要标记为：企业身份误判、关键词歧义、平台资料过期、同名企业混淆、主营已变化、证据不足、联系方式无效或其他。

## 三、回写规则

1. 不需要把所有 AI 候选企业都回写；
2. 只回写真正联系过、有价值、出错明显或未来可能复用的供应商；
3. 没有新增认知的未接通企业可以只保留电话验证记录，不进入反馈回写；
4. 新行业关键词只有经过人工沟通或可靠资料确认后，才加入下一轮关键词矩阵；
5. AI 判断错误时记录错误原因，用于调整搜索词、证据要求或分层口径；
6. “加入供应商库”只表示进入内部候选资料库，不等于合格供应商或已认证供应商；
7. 回写保持轻量，以一两分钟能够完成为宜，不扩展成复杂评分表或审批表。
