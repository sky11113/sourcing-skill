# 13 候选供应商证据链与分层模板

本模板用于深度模式的候选池建立、证据整理、A/B/C/D 分层和漏网检查。AI 分层只是公开资料初筛，不代表真实供应能力，不得写成“已认证供应商”或“合格供应商”。

## 一、候选池规则

1. 深度模式先建立30—50家候选池，再做证据补充和分层，不要一开始就给最终推荐；
2. 候选池阶段允许资料不完整，但必须标注疑点、未核实项和人工确认问题；
3. 不得为了凑数量加入明显不相关企业；合理搜索后不足30家时，输出实际数量并说明原因；
4. 同一集团、同一工厂的多个店铺或品牌需要标明关联关系，避免重复计数；
5. 用户要求排除的现有供应商或已联系供应商单列，不进入有效候选数；
6. 只有用户允许替代方案时，才把相近品类企业纳入候选池，并标记“替代路线候选”。

## 二、每家供应商的证据链字段

每家候选企业至少输出：

| 字段 | 记录要求 |
|---|---|
| 公司名称 | 使用可核验的工商或官网全称；无法确认时标记疑点 |
| 所在地区 | 省、市；生产地址与注册地址不一致时分别记录 |
| 主营业务 | 摘要公开资料，不把经营范围直接等同于实际产能 |
| 发现来源或线索 | 平台、搜索词、页面标题、链接及检索日期 |
| 主营匹配点 | 对应需求中的产品、工艺、应用或关键能力 |
| 供应商类型依据 | 判断为生产厂家、品牌方、代理商、贸易商或身份未核实的证据 |
| 风险或疑点 | 主体不一致、生产地址不明、资料过期、页面重复、报告不对应等 |
| 需要人工确认的问题 | 电话、微信、样品、文件或现场核验时要确认的具体问题 |

建议补充但不强制：官网、公开联系方式、关键设备或工艺证据、质量或合规资料、同类案例、产能与交期信息。找不到时写“资料不足，需人工确认”，不得编造生产线、案例、资质、电话、官网或联系人。

## 三、候选池输出表

```text
序号｜公司名称｜所在地区｜主营业务｜发现来源或线索｜主营匹配点｜供应商类型及依据｜风险或疑点｜需要人工确认的问题｜当前分层
```

## 四、A/B/C/D 分层规则

不使用复杂100分制。分层依据需求卡的硬性条件、供应商边界和证据充分程度：

- **A类：优先联系**。主营和关键能力高度匹配，供应商身份有较强公开证据，未发现硬性淘汰项，值得优先电话或微信核验；
- **B类：可备选**。方向基本匹配，但仍有生产属性、关键规格、交付、资质或案例需要人工确认；
- **C类：资料不足，待查**。存在相关线索，但公开资料不足或相互矛盾，暂不能判断是否值得进入报价或打样；
- **D类：暂不推荐或排除**。明显不匹配、触发硬性淘汰条件、属于用户排除对象、证据显示已停业，或只有无法交叉核验的弱线索。

分层必须附一句依据。不得因官网精美、平台排名、广告数量或单一认证直接判为 A 类。电话验证后允许调整分层，并记录调整原因。

## 五、漏网检查

完成首轮候选池和分层后，至少检查：

1. 是否覆盖产品正式名称、行业俗称和上下游叫法；
2. 是否从关键工艺、设备或能力词反向寻找企业；
3. 是否覆盖用户确认的地域及主要产业带；
4. 是否跨百度、1688、百度爱采购、企业信息平台、官网和行业平台寻找线索；
5. 是否检查候选企业的关联公司、生产主体或品牌主体；
6. 用户允许替代时，是否检查相近品类和替代技术路线；
7. 是否因排除词过宽误删了可接受的品牌方或代理商；
8. 是否存在重复店铺、同一工厂多主体或同一集团重复计数。

漏网检查输出：新增关键词、新增平台或地域、新增候选企业、去重情况、仍可能遗漏的范围。漏网检查不要求强行补足数量。

## 六、初筛声明

在候选池和分层结果末尾固定说明：

> 本结果基于公开信息进行 AI 初筛，不代表企业已通过采购、技术、质量或合规认证，也不证明其具备真实供货能力。所有关键结论必须通过电话、书面资料、样品、检测或现场审核进一步确认。资料不足的项目已标记“资料不足，需人工确认”。
