# 00 AI寻源需求澄清Skill V1.1 启动口令

以下口令可直接复制使用。无论选择哪种模式，都先自动判断物料类型，一次只追问一个核心问题，并在信息完整度达到约80%后停止需求追问。

达到约80%后，模式与执行方式统一使用组合编号，用户只需回复一个编号：

- `A1`：快速模式，只生成Prompt；`A2`：快速模式并联网找10—15家；
- `B1`：深度模式，只生成Prompt；`B2`：深度模式并联网建立30—50家候选池；
- `C1`：先快速后深度，先生成Prompt；`C2`：先快速后深度，并先联网执行一轮。

回复“默认”按 `C1` 处理。只回复 A/B/C 时仅补问 1/2；只回复 1/2 时仅补问 A/B/C。若当前AI不能联网，选择第二位 `2` 时说明限制并输出可交给联网AI使用的Prompt。

## 一、快速模式启动口令

```text
启动 AI寻源需求澄清Skill V1.1，使用快速模式。我要寻找：【填写物料、服务或替代对象】。

请自动判断物料类型并选择合适的追问模板，不需要我确认分类。一个问题一个问题追问，优先确认会影响规格、供应商类型、报价和验收的一级信息；我不知道的内容直接记为“待供应商确认”，不要换个说法反复追问。

信息完整度达到约80%后停止追问，生成寻源需求卡草案，然后用组合编号让我确认执行方式：A1只生成Prompt，A2联网形成10—15家候选方向。只需识别我的编号，不要求我复制完整选项文字。不得编造企业、参数、资质、联系方式或案例。
```

## 二、深度模式启动口令

```text
启动 AI寻源需求澄清Skill V1.1，使用深度模式。我要寻找：【填写物料、服务或替代对象】。

请自动判断物料类型并选择合适的追问模板，一个问题一个问题追问；未知信息写入“待供应商确认”。信息完整度达到约80%后停止需求追问，先生成寻源需求卡，再用组合编号让我确认执行方式：B1只生成Prompt，B2联网进入深度寻源执行。只需识别我的编号。

深度模式请自动生成关键词矩阵和分平台搜索策略，先建立30—50家候选池，再为每家整理证据链、风险疑点和人工确认问题，按A/B/C/D分层并完成漏网检查，最后输出电话验证表和轻量反馈回写表。AI分层只代表公开资料初筛，不得写成“已认证供应商”，不得为了凑数量加入明显不相关企业。
```

## 三、先快速后深度启动口令

```text
启动 AI寻源需求澄清Skill V1.1，使用先快速后深度模式。我要寻找：【填写物料、服务或替代对象】。

请先自动判断物料类型，一个问题一个问题追问，信息达到约80%后停止需求追问并生成需求卡，再用组合编号让我确认执行方式：C1先生成快速阶段Prompt，C2先联网形成10—15家初步候选方向。只需识别我的编号，不要求复制完整文字。

第一阶段结束后说明覆盖范围和缺口；只有我确认继续，才进入关键词矩阵、分平台搜索策略、30—50家候选池、证据链、A/B/C/D分层和漏网检查，并输出人工验证与反馈回写表。未知信息写“待供应商确认”，不得编造企业或证据。地域、供应商类型、替代方案、现供应商排除和候选数量等决策题优先给出字母选项，我只回复当前选项字母即可。
```
